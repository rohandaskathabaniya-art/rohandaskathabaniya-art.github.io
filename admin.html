Sign in with your GitHub token

This page has no password. Instead, GitHub checks a private token that only you have. Without it, nothing on the site can be changed, even though this page is public.

Need a token? Follow the steps below. Never share it with anyone.

How to create the token (2 minutes)
  1. On GitHub, click your profile picture, then Settings.
  2. Scroll down and click Developer settings, then Personal access tokens, then Fine-grained tokens.
  3. Click Generate new token. Name it Website admin.
  4. Expiration: choose 30 days.
  5. Repository access: choose Only select repositories and pick rohandaskathabaniya-art.github.io.
  6. Under Repository permissions, set Contents to Read and write. Leave everything else alone.
  7. Click Generate token, copy it right away and paste it above. GitHub shows it only once.

Help and security

How saving works

Each time you click Save and publish, this page sends your change to GitHub as a normal commit. GitHub Pages then rebuilds your site, which takes about a minute. Every change is recorded in your repository history, so you can always undo a mistake there.

Keeping it safe

  • Turn on two-factor authentication for your GitHub account.
  • Only use a token limited to this one repository, with 30-day expiry.
  • Never paste the token into the code, a chat, or a screenshot.
  • Sign out when you finish. You are also signed out after 20 minutes without activity.
  • If you think the token leaked, delete it in GitHub (Settings, Developer settings) straight away.
  • Use this page only on your own devices.
